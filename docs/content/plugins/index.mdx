# Plugins

These packages build on `typedoc-plugin-markdown` and are installed alongside it. Utility plugins change the Markdown it generates; themes shape that output for a particular docs platform or wiki.

## Utilities

Post-process the generated Markdown: add YAML frontmatter to each page, or run remark plugins over every file.
