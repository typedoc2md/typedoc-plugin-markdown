# Quick Start

<PackageVersion name={'typedoc-plugin-frontmatter'} />

## Installation

```sh npm2yarn
npm install typedoc typedoc-plugin-markdown typedoc-plugin-frontmatter --save-dev
```

## Usage

Add the plugins to your TypeDoc configuration file:

```json filename="typedoc.json"
{
  "plugin": ["typedoc-plugin-markdown", "typedoc-plugin-frontmatter"]
}
```

Add a docs script to your `package.json` file:

```json filename="package.json"
{
  "scripts": {
    "docs": "typedoc"
  }
}
```

Then build your documentation:

```bash filename="CLI"
npm run docs
```
